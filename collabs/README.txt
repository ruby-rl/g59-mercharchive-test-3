All known collabs already have a folder here, named to match your list.
To fill one in:

  1. Open the matching folder below
  2. Drop your photos straight in - any filenames are fine
  3. Delete that folder's ADD-PHOTOS-HERE.txt once you've added photos
  4. Commit and push - the site rebuilds itself automatically

Optional: add an info.json file inside a folder for a clickable date/link
line under the title. Without one, the folder name itself is the title.

Note: two small character swaps from your original list, since these
characters aren't allowed in folder names on Windows:
  - " /// " became " - "   (slash isn't allowed as folder-name text)
  - "*" became "-"         (GREY*59 -> GREY-59)
