All 78 known drops already have a folder here, named and dated to match
your list. To fill one in:

  1. Open the matching dated folder below
  2. Drop your photos straight in - any filenames are fine
  3. Delete that folder's ADD-PHOTOS-HERE.txt once you've added photos
  4. Commit and push - the site rebuilds itself automatically

A folder with no photos in it yet will just show an empty section on the
site until you add some.

Optional: add an info.json file inside a folder if you want a clickable
date/link line under the title (see the main README.md for the format).
Without one, the folder name itself is used as the section title exactly
as it appears here.

Note: a few folder names were adjusted slightly from your original list
because some characters aren't allowed in folder names (especially on
Windows):
  - "?" became "x"   (2015-??-?? -> 2015-xx-xx)
  - '"' became "'"   (quoted collection names)
  - "/" became "-"   (4/20 -> 4-20)
  - "*" became "-"   (GREY*59 -> GREY-59)
