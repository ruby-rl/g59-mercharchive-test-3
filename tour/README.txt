All known tours/shows already have a folder here, named and dated to match
your list. To fill one in:

  1. Open the matching folder below
  2. Drop your photos straight in - any filenames are fine
  3. Delete that folder's ADD-PHOTOS-HERE.txt once you've added photos
  4. Commit and push - the site rebuilds itself automatically

Optional: add an info.json file inside a folder for a clickable date/link
line under the title (see the main README.md for the format). Without one,
the folder name itself is used as the section title.

Note: " /// " in your original names became " - ", since "/" can't be used
inside a folder name on any operating system.
